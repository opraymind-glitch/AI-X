# データ収集方法の検討（草案）

> ステータス: draft — 確定したら docs/ に promote する

---

## 1. 施設データ（コンビニ・駅・ホテル位置）

### 現状
- Overpass API（OpenStreetMap）で無料取得中
- リアルタイムで会場周辺の施設を取得できている

### 課題
- OSMのデータ精度にムラがある（地方は情報が薄い）
- コンビニの閉店・移転がリアルタイムで反映されないケースあり

### 候補
| サービス | 費用 | 精度 | 備考 |
|----------|------|------|------|
| Google Maps Places API | 有料（月$200無料枠） | ◎ | 最も精度高い |
| Overpass API（現状） | 無料 | △〜○ | 今すぐ使える |
| Yahoo! ローカルサーチAPI | 無料枠あり | ○ | 国内特化 |

**→ 当面はOverpass継続。ユーザーが増えたらGoogle Maps APIへ移行を検討**

## 2. ホテル空室・料金情報

### 課題
- 位置情報だけならGoogle Maps / Overpassで取れる
- 空室状況・料金はリアルタイムAPIが必要
- Trivagoは直接APIを提供していない（アフィリエイト経由）

### 候補
| サービス | 費用 | 空室取得 | 備考 |
|----------|------|----------|------|
| **楽天トラベルAPI** | **無料** | **○** | 日本特化・登録のみで使える・最有力 |
| じゃらんAPI | 廃止傾向 | △ | 要確認 |
| Booking.com Affiliate | 無料（要審査） | ○ | 外資系・英語対応 |
| Trivago | アフィリエイトのみ | △ | 直接API提供なし |
| Hotels.com Affiliate | 無料（要審査） | ○ | Expediaグループ |

**→ 楽天トラベルAPIを最優先で調査する**
- 登録先: https://webservice.rakuten.co.jp/
- 主要エンドポイント: `Travel/SimpleHotelSearch`（緯度経度で周辺ホテル検索可）

## 3. マラソン大会情報

### 課題
- 公式APIを提供しているサイトがほぼない
- スクレイピングは利用規約の確認が必要
- 情報を分厚くしたい → 複数ソースの統合が必要

### 利用規約調査結果（2026-06-03 調査）

#### RUNNET（runnet.jp）
- **判定: スクレイピング❌ 無断利用不可**
- 第9条：サイト上のすべての著作権は当社に帰属
- 第10条：事前書面承諾なしに複製・二次的著作物の作成・譲渡・販売を禁止
- 最終条項：「大会データを含むすべての無断転載を禁じます」と明記
- → **提携・許諾交渉が必要。無断スクレイピングは不可**

#### スポーツエントリー（sportsentry.ne.jp）
- **判定: スクレイピング❌ 無断利用不可**
- 第8条：「私的利用の範囲を超えた複製・販売・出版等の使用」を禁止
- スクレイピングの明示的な禁止条項はないが、包括的な複製禁止が該当
- → **提携・許諾交渉が必要。無断スクレイピングは不可**

#### マラソン大会ドットコム / アールビーズ
- **判定: 未調査 → 要確認**

---

### 現実的な進め方（規約確認を踏まえた修正版）
1. **まず自前DBで主要大会（50〜100件）を手動整備**（リスクなし・今すぐ可能）
2. マラソン大会ドットコム等、規約が緩いサイトを追加調査
3. RUNNETへの**提携・データ提供依頼**を中長期で検討
4. 自前DBが充実したら独自クロールも将来的に検討（robots.txtの確認必須）

### 収集したい大会情報の項目
- 大会名・開催地（緯度経度）・都道府県・地域
- 開催日（年月日・週）
- 種別（ロード/トレイル/ウルトラ/トラック）・距離
- 定員・参加費・エントリー開始日・締切日
- 公式サイトURL・エントリーサイトURL
- 制限時間・コース特徴・高低差（トレイル）
